# SpendWise — Student Expense Tracker

SpendWise is a personal finance dashboard designed to help students track income, manage expenses, monitor monthly budgets, and understand their spending habits through a clean, modern interface.

## Live Demo

**[Launch SpendWise](https://spendwise-lsgu134zn-shreya-kadam1.vercel.app)**

## Features

- **Dashboard:** View your balance, total income, expenses, and savings.
- **Add Transactions:** Record income and expenses with transaction details.
- **Transaction History:** Review your recorded transactions.
- **Edit and Delete:** Update or remove existing transactions.
- **Analytics:** Visualize and review spending patterns.
- **Monthly Budget:** Set and monitor your monthly spending budget.
- **Persistent Storage:** Save transaction data in browser local storage.

## Run Locally

### Prerequisites

Install Node.js and Git.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kadamshreya030/Spendwise.git
   ```

2. Open the project directory:

   ```bash
   cd Spendwise
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

### Production Build

Run the following command to create a production build:

```bash
npm run build
```

## Data Storage

SpendWise uses browser local storage to persist transaction data. Data is stored locally in the browser and is not automatically synchronized across devices or browsers.
